# Veyquora Studio privacy policies

Public privacy policies for Veyquora Studio games, published with GitHub Pages at https://veyquorastudio.github.io/

| Game | Privacy policy |
|---|---|
| Hamster to Hound Pet Shop: Build & Grow | https://veyquorastudio.github.io/privacy/hamster-to-hound/ |

## Adding a game

1. Add `privacy/<game-slug>/index.html`: one self-contained page, with no scripts, trackers or files from other sites.
2. Link it from `privacy/index.html` and add a row to the table above.
3. Never move or rename a published policy: store listings point to its URL.

## What belongs here

Public policy pages only. Never game source code, builds, signing keys, credentials or internal documents.
